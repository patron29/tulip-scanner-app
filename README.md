# Product Scanner App 🛍️

A React-based product scanner application that allows users to scan barcodes, compare prices across retailers, and find coupons.

## Features

- 📱 Barcode scanning (simulated in web version)
- 🔍 Manual barcode search
- 💰 Price comparison across multiple retailers
- 🎟️ Coupon discovery and application
- ⭐ Product ratings and reviews
- 💾 Save favorite products
- 🏆 Product certifications display
